# Python 终端

## 它是什么

使用已选择的解释器，运行当前项目的 `.py` 文件或交互式 Python。输出实时显示在底部「终端」中。

终端不是系统 shell。脚本必须手动启动，没有自动重跑；这些限制不改变 Agent 自身的执行权限。

## 快速开始

1. 打开底部「运行时」，选择解释器；没有 Python 时可安装 Python 3.13.14。
2. 点击文件树中 `.py` 文件旁的 ▶，或文件页右上角的「运行」。
3. 在「终端」查看输出、输入内容，点击 ■ 停止或中断。

## 选择解释器

- Polaris 下载：独立安装，与系统 Python 隔离。
- 系统已装：使用检测到的 Python，不提供系统解释器的卸载操作。
- 手动指定：通过系统文件选择器选择 Python 或虚拟环境中的解释器。

状态栏显示当前解释器，点击可切换。手动指定的解释器被移动或删除后，需要重新选择。

## 安装一个 Python

- 来源：astral-sh 维护的 python-build-standalone，自带 pip。
- 可选版本：3.13.14（推荐）与 3.12.13。
- Windows x64 约下载 45 MB、安装后 126 MB；macOS（Apple Silicon）约 24 MB / 67 MB；Linux x64 约 114 MB / 318 MB。
- 安装在应用用户数据目录，不修改系统 PATH 或系统 Python。
- 下载完成后进行 SHA-256 校验，通过后才安装。

「运行时」显示下载、校验与解包进度。需要释放空间时，在该页面卸载由 Polaris 管理的解释器。

## 运行一个文件

在项目根目录下执行：

```
python -u <你的文件>
```

相对路径以项目根目录为准。`-u` 让输出实时显示；`input()` 可直接在终端中输入并回车。

## 交互式 Python（REPL）

点击「打开交互式 Python」，执行：

```
python -i -u
```

输入一行即可执行。不支持完整 TTY 的语法高亮与 Tab 补全。

## 装第三方包

在系统终端中，对当前选用的解释器执行：

```
<解释器> -m pip install <包名>
```

也可在交互式 Python 中运行：

```
import subprocess, sys
subprocess.run([sys.executable, '-m', 'pip', 'install', 'requests'])
```

安装位置由该解释器决定。建议使用独立 Python 或虚拟环境，避免影响系统依赖。

## 已知限制

- Windows 上没有真正的中断信号：「停止」会终止进程；macOS / Linux 的「中断」发送 SIGINT。
- 不支持完整 TTY，curses、光标控制和终端重绘可能无法正常工作。
- 输出超过 2000 行会截断，并显示提示。
- 只能运行项目目录内的文件。
- 中文列对齐受字体影响，使用 Sarasa Mono SC（更纱黑体）可改善等宽排版。

## 常见问题

### 找不到 Python？

在「运行时」安装一个解释器，或选择「我已经有 Python」手动指定。

### 装完还是跑不了？

检查解释器是否已选中、文件是否仍在原位置，以及脚本所需依赖是否已安装。

### 中文乱码？

默认使用 UTF-8。请检查脚本设置、输入文件编码和所选终端字体。

### 为什么不能运行项目外的文件？

终端只接受当前项目内的脚本。请先打开该脚本所在的项目，再运行文件。

### 终端里的会话去哪了？

切换页面不会终止会话，重新打开「终端」可继续查看输出。退出应用会结束会话。
