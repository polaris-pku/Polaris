# Polaris 总览

## 它是什么

Polaris 是面向软件开发的智能协作空间，将任务执行、Agent 协作、角色记忆和文件交付集中在本地项目中。

单 Agent 直接执行需求；多 Agent 合议通过提案、评审与综合完成协作。桌面版内置 Claude Code，无需另外安装 Node.js。

## 动手之前

### 模型服务

需求正文和执行器读取的项目内容会发送到配置的模型服务商。请勿提交禁止外发的代码或数据。API Key 保存在本机，用于模型调用，不回传界面。

### 文件与执行权限

Agent 会直接执行命令并修改文件，权限请求默认自动放行，没有写入前确认。Polaris 不是沙箱，请在有版本控制的可信项目中使用。

### 用量与费用

计费 token、上下文占用和分阶段用量互不相加。实际花费以服务商账单为准；尚未结算或缺失的数据会单独标记。

## 快速开始

1. 打开「设置 → 模型与认证」，选择服务商并填写自己的 API Key。自定义服务还需填写端点和模型，然后「保存并重启后端」。
2. 在首页新建项目，或通过「打开项目 → 从文件夹打开」选择已有目录。
3. 点击「新建需求」，填写需求与验收标准，选择「单 Agent」或「多 Agent 合议」，再创建任务。
4. 在运行页查看进度、活动与用量，在项目文件树查看交付文件。

「Agent 控制台」提供角色画像、技能、经验与生命周期管理。「设置 → 驱动路由」可调整角色的执行器，保存后只影响新运行。

## 一次需求会经历什么

运行页展示已发生的步骤；一个需求可由多次运行推进。

### 需求受理

创建任务并开始执行。

### 分派与上下文

展示执行角色及上下文准备状态。

### Agent 执行

执行器处理需求、调用工具并修改项目文件。「当前活动」显示思考、委派和工具状态。

### 产出

展示已登记的文件与候选实现。产物列表不等于全部磁盘改动，必要时使用 `git diff` 查看。

### 审查

展示已配置策略的检查结果，不代替完整测试或人工审核。

### 交付

按最终任务状态确认交付，项目文件树同步交付报告中的文件路径。等待协作回复时，单次运行结束不代表需求已完成。

选择「多 Agent 合议」时，还会出现「议会」步骤，可查看提案、评审与综合结果。

## 文件去了哪

- 已有项目：使用打开时选择的目录。
- 新建项目：未指定位置时，保存到系统「文档」目录下的 `polaris-workspace/<项目名>`。
- 文件定位：打开文件页，点击右上角的文件夹图标，在系统文件管理器中查看。

文件树会补入交付报告中的已写入文件，但不是磁盘实时镜像。外部程序增删的文件需要重新扫描：从侧栏移除项目，再从文件夹打开。

移除项目或文件树节点不会删除磁盘文件。失败或退出前已经写入的文件也不会自动撤销。

## Python 终端

在底部「运行时」中选择或安装 Python，再点击文件树中 `.py` 文件旁的 ▶。也可在「终端」中打开交互式 Python。

终端只能运行当前项目的 Python 文件或 REPL，不是系统 shell。脚本需手动启动，没有自动重跑。安装包、第三方依赖与平台差异见「Python 终端」。

## 观测：你能看到什么

- 运行页：执行阶段、当前活动、用量与交付结果。
- 事件流：原始事件及完整载荷；内容不可读取时显示原因。
- 状态栏：当前任务、连接状态与 Python 解释器。
- 运行记录：在项目菜单中导出 JSON，保存到项目的 `.polaris/` 目录。

连接中断时显示「执行状态待同步」，重连后重新读取运行状态。「已连接」只表示通道可用；活动陈旧时仍需查看最近事件。

## 已知限制

- 同一角色的任务按队列执行，等待时间计入运行时长。
- 不能跨项目并行提交；存在运行中或等待协作的任务时，不能切换后端工作区。浏览其他项目不受影响。
- 运行中不能追加对话或修改已提交的需求。运行页没有取消按钮；退出应用会终止相关执行进程。
- 界面不展示逐 token 的回复正文。
- 合议没有人工裁决通道；Gate 结论也只能查看，不能从界面回复。
- 不提供文件回滚；需要恢复改动时请使用项目的版本控制。
- 打包版默认只分发 Claude Code；其他执行器需单独安装并配置。
- 文件树不是磁盘实时镜像，未列入交付报告的改动需到项目目录确认。
- 启动会恢复历史任务与项目归属，但仍停留首页。导出的运行记录不能导回应用。
- Python 终端不是真正的 TTY，不支持依赖完整终端控制的程序。

## 常见问题

### 文件没有出现在列表里？

先到项目目录检查磁盘文件和 `git status`。交付报告之外的改动不会自动加入文件树，可移除项目后从文件夹重新打开。

### 运行长时间没有变化？

查看「当前活动」、最近事件与连接状态。同一角色已有任务时，新任务需要等待；连接恢复后状态会重新同步。

### 刚提交就失败？

检查模型配置和页面中的错误信息。修正配置后重启后端，再重新提交需求；失败前写入的文件仍可能保留在项目中。

### 如何停止执行？

退出应用会结束相关执行进程，已写入的文件不会回滚。再次运行前可先检查项目改动。
